## 🎯 Overview

**EnergySage** helps households and industries **monitor, forecast, and optimize** energy use. It detects anomalies, predicts future demand, and surfaces actionable recommendations with **cost and CO₂ savings** — all through interactive dashboards and a real-time simulation, with a **household / industry** mode switch.

> 🧪 **Prototype note:** the app runs **entirely client-side** — readings are generated by a realistic simulator (optionally seeded by an imported CSV), and analysis runs in the browser. Auth is a lightweight demo (localStorage token), so there's no backend to deploy.

## ✨ Features

- **📄 Data Import** — upload a CSV of energy readings or an appliance list to seed the dashboard
- **⚡ Real-Time Simulation** — live-consumption simulator with cumulative totals and session tracking
- **📊 Interactive Dashboards** — time-series and breakdown charts (Recharts) for household or industry mode
- **🕒 Time-Based Analysis** — day/night and trend-aware usage patterns with wastage thresholds
- **🚨 Smart Alerts & Notifications** — anomaly + grid-awareness notifications
- **🤖 Recommendations** — actionable steps with cost / CO₂ impact
- **🌱 Carbon Footprint Analysis** — emissions breakdown and offset links
- **🔮 Predictive Maintenance** — at-risk equipment signals
- **🏆 Benchmark & Energy Score** — compare usage and score efficiency
- **📈 Performance Monitor** — live app performance metrics

## 🚀 Getting Started

### Prerequisites
- **Node.js 20** and **pnpm** (`corepack enable`)

cd EnergySage/shadcn-ui

## 📡 How the "API" Works

There is no server — [`src/lib/api.ts`](shadcn-ui/src/lib/api.ts) is an in-browser engine. It exposes typed interfaces and functions that:

- **Simulate** energy readings over time (per appliance / machine, with cumulative kWh and session windows)
- **Analyze** the stream for anomalies (actual vs expected kWh with low/medium/high severity) and forecast future demand with confidence intervals
- **Score** usage against time-of-day baselines to flag wastage

To plug in a real backend, swap the local functions in `api.ts` for `fetch` calls to your endpoints — the return types (`EnergyReading`, `Prediction`, `Anomaly`, …) are already defined.

## 🔐 Auth

`/auth` sets a demo token and user (with `household` / `industry` mode) in `localStorage`. Mode changes which dashboard layout and analysis thresholds apply. Swap in a real identity provider for production.
